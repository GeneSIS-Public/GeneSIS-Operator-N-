# ARCHITECTURE
## Public model architecture

```text
Private Raw Sources
  ↓
Private Canonical Working Model
  ↓
Public Filter
  ↓
GeneSIS-Operator(N)
  ↓
Public Views / Documents
```

## Principle

```text
Raw ≠ Model ≠ View
```

Raw Sourceと公開Interpretationは同一ではない。Private Sourceを公開せずにPatternだけをPublic ViewへExposeできる。

## Public Narrative Sources

公開済みnote記事、Project documentation、Release notes等は、将来的にPublic Evidence Sourceとして参照可能。

```text
Public article
     ↓
EVIDENCE reference
     ↓
SPEC pattern
```

## Export Philosophy

```text
Canonical Model
     ↓
Audience / Purpose / Bandwidth
     ↓
Renderer
     ↓
Output
```

The model is not the document. The document is one export.
