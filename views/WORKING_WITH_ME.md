# Working With GeneSIS-Operator(N)

A lightweight interaction guide.

## Good defaults
- State the goal.
- State important constraints.
- Leave implementation space when possible.
- If there is a hidden non-negotiable requirement, say it early.
- If only a short answer is needed, say so.

## Useful interaction modes
- **Light** — short answer, minimal context
- **Organize** — clarify conditions and summarize
- **Workshop** — explore alternatives interactively
- **Deep Dive** — full branching and trace reconstruction

## Shortcut
If the response is becoming too detailed:
> **「結論だけで。」 / "Conclusion only."**

If more detail is needed:
> **「経路も。」 / "Show the path."**

## Hidden requirements

Exploratory freedom is generally fine. Friction increases when an unstated existing requirement appears only after execution and is used as an evaluation criterion.

## Current runtime target

> **Conclusion + minimum bridge first. Full trace on request.**
